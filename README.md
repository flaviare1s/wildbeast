# 🐺 Wildbeast

![Banner do Projeto](https://img.shields.io/badge/Status-Conclu%C3%ADdo-brightgreen?style=for-the-badge)
![UI Responsiva](https://img.shields.io/badge/Design-Responsivo-blueviolet?style=for-the-badge)
![CSS Grid](https://img.shields.io/badge/Layout-CSS_Grid-orange?style=for-the-badge)

O **Wildbeast** é uma vitrine digital imersiva dedicada ao mundo animal. O projeto foca em uma interface limpa, tipografia elegante e um layout robusto utilizando as melhores práticas de **CSS Grid Layout** e **Flexbox** para proporcionar uma experiência de navegação fluida em qualquer dispositivo.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias modernas de front-end, sem dependências externas, garantindo performance e leveza:

*   ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white) - Estruturação semântica.
*   ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white) - Estilização avançada com Grid e Flexbox.
*   ![SVG](https://img.shields.io/badge/SVG-FFB13B?style=for-the-badge&logo=svg&logoColor=white) - Ícones vetoriais de alta fidelidade.

## 🛠️ Estrutura do Projeto

A organização de pastas segue o padrão de clareza e manutenibilidade:

```bash
.
├── css/
│   └── style.css          # Estilização global e layouts de Grid
├── img/
│   ├── anuncio-1.jpg      # Assets de publicidade
│   ├── wolf1.jpg          # Galeria principal
│   ├── wildbeast.svg      # Logo oficial
│   └── icones/            # Icons (Abelha, Cervo, Gato, Leão, etc)
└── index.html             # Estrutura principal do site
```

---

## 🎨 Funcionalidades

-   **Layout Grid Avançado:** Utilização de áreas de grid para um posicionamento preciso de elementos.
-   **Galeria Imersiva:** Exibição de imagens de alta qualidade com foco em vida selvagem.
-   **Ícones Customizados:** Integração de SVGs para uma interface leve e escalável.
-   **Sidebars Informativas:** Seções laterais otimizadas para anúncios e navegação contextual.

## 📦 Como Instalar e Rodar

Não são necessárias dependências ou compiladores. Siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/flaviare1s/wildbeast.git
    ```

2.  **Navegue até o diretório:**
    ```bash
    cd wildbeast
    ```

3.  **Abra o projeto:**
    Basta abrir o arquivo `index.html` em seu navegador de preferência ou utilizar a extensão **Live Server** do VS Code.

## 💡 Como Usar

Este projeto serve como uma excelente base de estudo para:
